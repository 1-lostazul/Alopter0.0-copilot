# App module (Android) — AIopter

This is a minimal Android app scaffold for AIopter. It contains a placeholder MainActivity implemented with Jetpack Compose.

Notes:
- ApplicationId: com.aiopter.app
- minSdk: 24, targetSdk: 34
- This scaffold does not include the Gradle wrapper (gradlew). Add the Gradle wrapper or use your local Gradle installation to build.

How to run locally (when Gradle wrapper present):
1. Ensure Android SDK is installed and ANDROID_HOME is set.
2. From the repo root: ./gradlew :app:installDebug

Do not enable or test any screen-capture or overlay features without reviewing the privacy checklist in docs/SECURITY_AND_PRIVACY.md.
