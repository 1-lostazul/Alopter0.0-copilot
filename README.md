AIopter

AI that’s there when you need it.

AIopter is a floating, permission-first AI assistant designed to work alongside the user across Android apps.

The eventual product will include:

- A draggable floating AIopter rotor/bubble above other apps
- Tap-to-open compact AI assistant panel
- Text questions
- Voice questions
- AI answers
- User-controlled screen sharing
- Clear screen-sharing status
- Permission-based access to apps and information
- Allowed Apps list
- Never Allow list
- Additional authorization for sensitive information
- Quick Kill button
- Verbal stop/kill command
- Internet-supported questions such as weather, maps, research, recipes, education, and general information
- Context-aware help based on what the user is viewing, but only when permission has been granted
- Strong privacy, security, transparency, and user control

Important AIopter principles:

1. The user stays in control.
2. AIopter should request permission before sensitive access.
3. Screen access must be obvious when active.
4. Sensitive actions require additional confirmation.
5. The user must always have an immediate way to stop AIopter.
6. Never hide monitoring or data access.
7. Collect only information needed to perform the requested task.
8. Security and privacy are product requirements, not optional features.

Brand direction:

- Product name: AIopter
- The official symbol is a blue/cyan three-part rotor/swirl shaped clearly like the letter O.
- The rotor replaces the “O” in the AIopter wordmark.
- That same rotor will eventually serve as the Android app icon and the floating on-screen assistant button.
