# Security policy

If you discover a security vulnerability in AIopter, please do not open a public issue. Instead:

1. Contact the maintainers privately at 1aspires2ai@gmail.com with details and steps to reproduce.
2. If email is not available, create a private repository security issue or use the GitHub Security Advisories flow.

We will acknowledge receipt within 3 business days and coordinate a fix and disclosure timeline.

Do not include exploit code in public reports until a fix is available.
