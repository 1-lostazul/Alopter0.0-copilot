# Google Play Release Checklist

## Account and app setup
- [ ] Create Google Play Console developer account
- [ ] Create application entry
- [ ] Configure app signing (Play App Signing)
- [ ] Prepare release keystore backup process

## Build and quality
- [ ] Build release AAB
- [ ] Verify versionCode/versionName policy
- [ ] Run internal testing
- [ ] Run closed testing
- [ ] Resolve top crashes/ANRs before production

## Store listing assets
- [ ] App title
- [ ] Short description
- [ ] Full description
- [ ] Screenshots (phone)
- [ ] Feature graphic
- [ ] Category and tags
- [ ] Contact details
- [ ] Privacy policy URL

## Compliance
- [ ] Data Safety form complete
- [ ] Content rating questionnaire complete
- [ ] Ads declaration set correctly
- [ ] Sensitive permissions justified with in-app disclosure

## Monetization setup
- [ ] Configure primary model (ads for free tier)
- [ ] Verify ad placement does not block onboarding
- [ ] Add post-launch revenue dashboard (CPM, fill rate, ARPDAU)

## Launch
- [ ] Staged rollout enabled
- [ ] Monitor crash-free users and ANRs daily during rollout
- [ ] Respond to early user reviews

## Post-launch growth
- [ ] A/B test title/screenshot variants
- [ ] A/B test ad placements
- [ ] Expand to higher-CPM geographies while monitoring retention
