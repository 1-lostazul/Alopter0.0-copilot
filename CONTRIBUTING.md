# Contributing to Alopter0.0-copilot (AIopter)

Thanks for your interest in contributing to Alopter0.0-copilot. This repository is the source-of-truth for the AIopter product. Please follow these guidelines to make contributions fast and easy to review.

How to contribute

- Search existing issues and PRs before opening a new one.
- For bugs and feature requests, use the issue templates.
- Fork the repository and open a topic branch for your changes.
- Keep changes small and focused. One feature or fix per PR.

Pull request checklist

- [ ] The code builds and runs (if applicable).
- [ ] New and existing unit tests pass locally.
- [ ] Linting and static analysis are clean.
- [ ] The PR description explains the "why" and the design choices.
- [ ] Documentation updated where applicable (docs/, README.md).

Developer environment

- We use Kotlin and Jetpack Compose for Android. No app code exists yet — wait for a follow-up scaffold or request an app module scaffold.
- To run CI locally: ensure you have Docker (for super-linter) and optionally Gradle if an Android module exists.

Communication

- Use issues for design discussions.
- Use the project board (Roadmap) for planning and tracking milestones.

Thank you for improving AIopter — we appreciate your time and effort.
